# 个人主页 / 作品集

一个纯静态的个人主页，用来放我做过的东西。没有框架、没有构建步骤、没有外部依赖。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面内容：名字、介绍、技能、项目卡片、联系方式 |
| `style.css` | 样式。顶部 `:root` 里是配色变量，改一处全站生效 |
| `snake-game/` | 第一个作品「霓虹贪吃蛇」，项目卡片直接链过去 |

## 本地预览

双击 `index.html` 即可，断网也能看。

## 改内容

- 名字、介绍、邮箱、项目卡片 —— 都在 `index.html`
- 配色 —— 改 `style.css` 里的 `--accent`
- 加新项目 —— 复制一整块 `<article class="card">...</article>`，改标题、描述、标签、链接

## 上线（GitHub Pages）

仓库设为 Public → Settings → Pages → Source 选 `main` 分支、目录 `/ (root)` → 保存。
等一两分钟，会得到一个 `https://用户名.github.io/仓库名/` 的链接。

> 本目录就是仓库根目录，直接把这里的内容推上去即可。
> 项目卡片里指向 `./snake-game/index.html`，所以 `snake-game` 文件夹必须一起提交，否则链接会失效。
